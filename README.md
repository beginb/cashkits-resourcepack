# CashKits Resource Pack

Public asset host for the CashKits Minecraft server. No plugin code or server details live here -- just the packaged resource pack zip, rebuilt and re-uploaded whenever the pack changes.

Currently: custom worn-armor textures for the VoidGuard crate-exclusive armor set (a real `minecraft:equippable` asset, not a material texture override -- gracefully degrades to plain netherite for anyone who hasn't accepted the pack).

Source/generator: `tools/generate_voidguard_armor.py` in the private `cashevent` repo.
