# CashKits Meteor Mace Resource Pack

Public asset host for the CashKits Minecraft server's Meteor Mace feature (charge-tier mace textures + impact sound layers). No plugin code or server details live here -- just the packaged resource pack zip, rebuilt and re-uploaded whenever the pack changes.

Source/generator: `tools/generate_meteor_textures.py` in the private `cashevent` repo.
